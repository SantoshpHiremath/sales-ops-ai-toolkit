# Sales Ops AI Toolkit

A tested Python toolkit that combines three sales-operations capabilities:
AI-powered capture planning, prompt engineering for sales outreach, and
lead scoring with CRM data quality.

## What it does

- **`src/leads.py`** — synthetic B2B sales-lead generator (900 leads by
  default) with realistic feature/outcome correlation plus injected
  noise and ~12% missing fleet-size data, mirroring an imperfectly
  maintained real CRM rather than a clean synthetic set.
- **`src/scoring.py`** — a lead-scoring classifier (scikit-learn
  logistic regression + one-hot encoding of categorical fields),
  evaluated with a genuine held-out train/test split. It supports process
  optimization through lead scoring, and data maintenance and quality
  assurance.
- **`src/capture_plan.py`** — assembles a structured capture-plan
  document from account facts plus an extractive summary of free-text
  notes (e.g. public report excerpts).
- **`src/outreach.py`** — parameterized prompt templates for
  personalized outreach emails across three sales angles (cost
  displacement, greenfield capability, renewal/upsell), plus a
  deterministic no-LLM fallback.
- **`src/pipeline.py`** — runs the full flow end-to-end: generates
  leads, trains and evaluates the scoring model, then produces a sample
  capture plan and outreach prompt/email for a realistic account.

## Data

The lead-scoring data is synthetic, generated by `src/leads.py`; it is not
any real company's CRM data. Feature-to-outcome relationships (budget
confirmed, engagement, prior customer, fleet size, etc.) are designed to be
realistic in direction but deliberately noisy, so the model learns from
imperfect signal rather than a disguised deterministic rule. The pipeline is
built so real CRM exports can replace it.

## Scope

Capture-plan and outreach text generation uses classical NLP (extractive
summarization + parameterized prompt templates) and does not call a large
language model:

1. `build_outreach_prompt()` generates the actual prompt text that would
   be sent to an LLM in production. It is inspectable and testable for
   structure and personalization on its own.
2. `render_template_email()` is a deterministic template-fill fallback
   that produces a working, sendable-quality draft without needing any
   LLM. It is less fluent than what an LLM would generate from the
   prompt above.

The capture-plan account summaries use **extractive summarization**
(frequency-scored sentence selection), not generative summarization:
every sentence in a summary is lifted verbatim from the input notes, so
nothing is fabricated, at the cost of being less fluent than an
LLM-generated summary would be.

## Results

The lead-scoring evaluation is built to guard against label leakage:
`train_and_evaluate()` uses `train_test_split` with stratification on the
actual row-level dataset (not a small finite template pool), and a dedicated
test (`test_accuracy_is_not_suspiciously_perfect`) asserts accuracy stays
below 90% as a regression guard. If that test ever starts failing, it means
something is leaking the label into a feature, not that the model "got
better."

Current numbers (900 synthetic leads, 25% held-out test set, seed 42):
**65.3% accuracy** against a 42.7% positive-class base rate in the test set
(so a "predict majority class always" baseline would score 57.3%),
**ROC-AUC 0.69**, precision 0.60, recall 0.56. This is a modest but genuine
lift over baseline, consistent with how noisy real sales data tends to be.

## Tests

29 automated tests (`tests/test_sales_ops_toolkit.py`) covering: lead
generation determinism and realism (no degenerate all-0/all-1 labels,
missing data present), the scoring model's train/test split integrity,
the "not suspiciously perfect" regression guard, sane precision/recall/
ROC-AUC bounds, correct handling of unseen categorical values at
inference time, a directional sanity check (leads with strong positive
signal score higher than leads with weak signal), extractive-summary
correctness (summary sentences must come verbatim from the source text,
in original order), capture-plan field assembly, and outreach-prompt/
email personalization and input validation.

## Running it

```bash
pip install scikit-learn pandas
python3 src/pipeline.py          # generates leads, evaluates the scoring model, prints a sample capture plan + outreach prompt
python3 -m pytest tests/ -v      # runs all 29 tests
```

## Possible extensions

- Replace the template/extractive generation with LLM calls using the
  prompts from `build_outreach_prompt()`.
- Score real CRM exports in place of the synthetic leads.
